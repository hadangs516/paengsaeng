# 팽생역전 - 팽이 키우기 RPG

동네 꼴찌에서 팽이왕까지! 팽이를 키우고 라이벌을 쓰러뜨리는 팽이 배틀 RPG.

- 플레이: https://hadangs516.github.io/paengsaeng/
- 모바일, PC 모두 가능 (빌드 없는 HTML/CSS/JS)
- 진행 기록은 브라우저에 저장됨. 다른 기기로 옮길 때는 설정 → 기록 옮기기

## 조작
- 발사: 원이 노란 원에 겹칠 때 탭 (PC: Space)
- 이동: 화면 드래그 (PC: WASD / 방향키 / 마우스 드래그)
- 대시: 대시 버튼 (PC: Space)
- 필살기: 게이지가 차면 필살기 버튼 (PC: E)
